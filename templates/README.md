# Drafting prompts for external AI agents

Pick the file for the category you're drafting next, open it, and copy the
entire code block, then paste it as-is to an AI agent with no context of
this repo (a fresh session, a different tool, one with web search but no
filesystem access). Hand its output back to Claude in this repo afterward —
each prompt already stamps a `category` field on every entry, so you don't
need to state which category the file is for.

These prompts are maintained by Claude, not you — after reviewing an
inbox batch, Claude updates the relevant category's `AVOID THESE ANGLES`
list directly in that category's file. You should never need to copy text
between files or edit these by hand.
